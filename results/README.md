# 📈 Results

This folder will contain **experimental results, benchmarks, and evaluation metrics** from the Kubernetes Cost Optimization Framework.

## Expected Contents (Phase-II & III)

| File | Description |
|------|-------------|
| `cost_savings_analysis.md` | Before/after cost comparison showing monthly cloud spend reduction |
| `forecasting_accuracy.md` | ML model evaluation metrics (RMSE, MAE, MAPE) for demand forecasting |
| `performance_benchmarks.md` | Latency and throughput benchmarks (p50, p95, p99) under optimized configurations |
| `scaling_efficiency.md` | HPA response time analysis — reactive vs. proactive scaling comparison |
| `charts/` | Visualization charts and graphs for the final report and presentation |

## Target Metrics

| Metric | Target |
|--------|--------|
| Monthly cost reduction | 25–40 % |
| Forecast accuracy (MAPE) | < 15 % |
| p99 latency under load | < 500 ms |
| Spot instance adoption | > 60 % for batch workloads |
